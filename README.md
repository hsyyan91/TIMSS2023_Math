# TIMSS2023_Math

## Requirements & Environment

This code was developed and tested on **Python 3.13.7** with the following key dependencies:

* **pandas** == 2.3.2
* **numpy** == 2.3.2
* **scikit-learn** == 1.9.0
* **scipy** == 1.18.0
* **xgboost** == 3.4.0
* **lightgbm** == 4.7.0
* **matplotlib** == 3.11.1
* **seaborn** == 0.13.2

### Quick Setup

To install all dependencies, run:

```bash
pip install pandas==2.3.2 numpy==2.3.2 scikit-learn==1.9.0 scipy==1.18.0 xgboost==3.4.0 lightgbm==4.7.0 matplotlib==3.11.1 seaborn==0.13.2
